# Expense Tracker – Full Stack MERN Application

## Brief One-Line Summary
A full-stack MERN Expense Tracker application with JWT authentication, transaction management, analytics dashboard, and a modern responsive UI.

---

# Overview

Expense Tracker is a production-style full-stack web application developed using the MERN stack. The application allows users to securely manage their income and expenses with JWT authentication and protected routes.

The project focuses heavily on:
- Secure backend architecture
- Authentication flow
- MongoDB aggregation pipelines
- State management
- Scalable frontend structure

Users can:
- Register/Login securely
- Add and delete transactions
- Track income and expenses
- View financial analytics
- Monitor balance summaries

The application uses a modern dark SaaS-inspired UI with responsive layouts and clean dashboard components.

---

# Problem Statement

Managing daily expenses manually becomes difficult when users:
- Lose transaction records
- Cannot analyze spending habits
- Lack proper financial summaries
- Have no categorized insights

This project solves these problems by providing:
- Secure transaction management
- Real-time expense tracking
- Monthly and category-based analytics
- Organized financial dashboards

through a complete full-stack MERN architecture.

# How to Run Project

## Clone Repository

```bash
git clone https://github.com/Sham1718/expense-tracker
```

---

## Backend Setup

```bash
cd backend
npm install
npm run dev
```

---

## Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

---

## Environment Variables

Create a `.env` file inside the backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

## Frontend Server

```bash
http://localhost:5173
```

## Backend Server

```bash
http://localhost:5000
```
